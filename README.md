Le but de ce projet est de développer un générateur de mèmes avec lequel les utilisateurs pourront:
-Choisir des images pour créer leurs mèmes 
-Ajouter du texte 
-Visualiser les modifications en temps réel 
-Télécharger et partager  leurs mèmes
-Avoir une galerie pour visauliser les mèmes créés 

Les technologies utilisées sont : HTML, CSS, JavaScript. 

Nous avons deux dossiers principaux:
-Le dossier view 
à l'intérieur duquel il y'a nos vues, donc nos pages HTML.
-Le dossier ressources 
qui contient deux sous dossiers, l'un pour les scripts JavaScript et 
l'autre pour les styles 

***VOIR LE RENDU***
-Télécharger les différents fichier (ressources et view)
-Ouvrir la page index.html et naviguer entre cette page et la page galerie.html

les différentes fonctionnalités ont été bien développées...
